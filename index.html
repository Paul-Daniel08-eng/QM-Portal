DQC framework at a glance

  1. Selection of DQC parameter
  2. Identification of the standard to be challenged
  3. Data collection
  4. Process performance study: Pp, Ppk ≥ 1.33 to proceed; below 1.33, improve process performance and collect data again
  5. Monitoring using control charts (3 months): if not stable, address abnormality; if stable, proceed
  6. Process capability study (minimum 50 subgroups): Cp, Cpk ≥ 1.33 to proceed; below 1.33, improve the process
  7. Do we need a new standard for benchmark? Yes: define the new standard and justify it (business criteria), then back to data collection. No: justify the decision of not raising the standard, then back to control-chart monitoring

Key thresholds

  • Pp, Ppk ≥ 1.33 (process performance study)
  • Cp, Cpk ≥ 1.33 (process capability study)
  • Minimum 50 subgroups for the capability study
  • 3 months of monitoring on control charts

Source: DQC Framework flow chart.

How the portal reads progress

  • Parameter health % = points achieved ÷ points possible in the activity matrix (21 steps: SOP 6, IDC 1, Ppk 3, SPC 5, Cpk 6)
  • Qty = parameters with every step in the group completed
  • SOU totals count each parameter once and take the higher health % when it is in two projects
